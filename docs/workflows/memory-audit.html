Memory & Audit

A Friday cleanup job. Reviews this week's structured findings, flags items that need human review (low confidence but high relevance), and writes a quality summary to the execution log.

Workflow IDskUbNsPy00W8DiDa
Triggered byMaster Orchestrator · Fridays, after Newsletter
AI modelNone: deterministic logic only
Writes toexecution_log (Google Sheets)
Reads fromstructured_findings
info How It Works

Memory & Audit is the last workflow to run each Friday. After the Newsletter has been sent, this workflow scans the week's findings for items that deserve human review: things that the automated system flagged as uncertain but potentially important.

The flagging logic is deterministic: any finding where confidence_score ≤ 2 AND relevance_score ≥ 4 is flagged, OR where review_flag = TRUE was already set by the AI during Competitor Intelligence. The audit produces a weekly quality summary: total findings, flagged count, list of flagged IDs with reasons.

This summary is written to execution_log: giving a historical record of each week's quality metrics over time.
