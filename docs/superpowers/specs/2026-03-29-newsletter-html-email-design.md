# Newsletter HTML Email — Design Spec

_Date: 2026-03-29_

---

## Problem

The PI: Newsletter workflow sends Gmail as plain text (`emailType: "text"`). Claude's output uses markdown (`##`, `**`, `---`, `-`), which renders as literal symbols in Gmail. The email is unreadable as a formatted document.

## Scope

Email (Gmail) only. Notion is out of scope for this change.

## Approach

Option A: Add a markdown-to-HTML conversion Code node. Claude continues to produce markdown content — no prompt changes. A new node converts the output to styled HTML before the Gmail send.

---

## Changes

### 1. New node: "Format HTML Email"

**Position:** Between "Build Newsletter Output" and "Send Gmail Newsletter"

**Input:** `$json.newsletter_content` (Claude's markdown string)

**Output:** `$json.newsletter_html` (full HTML email string)

**Conversion rules (simple string parsing, no library):**

| Markdown pattern | HTML output |
|---|---|
| `## SECTION TITLE` | `<h2>` with colored left border accent |
| `**text**` | `<strong>text</strong>` |
| `---` | `<hr>` styled as light divider |
| `- bullet text` | `<li>` inside `<ul>` |
| Plain paragraph text | `<p>` |

**Template structure:**
```
<html>
  <body> (light gray background, #f4f4f4)
    <div> (white card, 600px max-width, centered, padding 32px)
      <header> (dark navy #1a2744, white text, "PI Weekly Intel — YYYY-MM")
      <content> (converted markdown sections)
      <footer> (small gray text: "Generated by Product Intelligence OS")
    </div>
  </body>
</html>
```

**CSS approach:** All styles inline (required for Gmail compatibility). Font: Arial/Helvetica. Section `<h2>` has a 4px left border in orange/red accent (#e85d04).

### 2. Updated node: "Send Gmail Newsletter"

| Field | Before | After |
|---|---|---|
| `emailType` | `"text"` | `"html"` |
| `message` | `$json.newsletter_content` | `$json.newsletter_html` |

---

## What Does Not Change

- Claude prompt and content generation — untouched
- All other nodes — untouched
- Notion path — untouched (future work)
- Workflow connections except the new node insertion

---

## Success Criteria

- Gmail renders section headers as styled headings, not `## text`
- Bold company names render as bold, not `**text**`
- Horizontal rules render as visual dividers, not `---`
- Bullet points render as proper list items
- Email is readable and professional-looking at 600px width
