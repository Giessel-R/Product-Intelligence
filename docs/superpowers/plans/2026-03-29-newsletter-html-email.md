- [ ] **Step 2: Confirm the full Code node JavaScript**

This is the exact code to use in the "Format HTML Email" node:

```javascript
const data = $input.first().json;
const content = data.newsletter_content || '';

function parseMarkdown(text) {
  const lines = text.split('\n');
  let html = '';
  let inList = false;

  for (const line of lines) {
    if (inList && !line.startsWith('- ')) {
      html += '</ul>';
      inList = false;
    }

    if (line.startsWith('## ')) {
      const title = line.substring(3).trim();
      html += `<h2 style="color:#1a2744;font-size:13px;font-weight:700;text-transform:uppercase;letter-spacing:0.08em;border-left:4px solid #e85d04;padding-left:12px;margin:28px 0 10px 0;">${title}</h2>`;
    } else if (line.trim() === '---') {
      html += '<hr style="border:none;border-top:1px solid #e5e7eb;margin:24px 0;">';
    } else if (line.startsWith('- ')) {
      if (!inList) {
        html += '<ul style="margin:8px 0 8px 0;padding-left:18px;">';
        inList = true;
      }
      const itemText = line.substring(2).replace(/\*\*(.*?)\*\*/g, '<strong>$1</strong>');
      html += `<li style="margin:6px 0;color:#374151;font-size:14px;line-height:1.65;">${itemText}</li>`;
    } else if (line.trim() === '') {
      // skip blank lines — spacing handled by element margins
    } else {
      const paraText = line.replace(/\*\*(.*?)\*\*/g, '<strong>$1</strong>');
      html += `<p style="color:#374151;font-size:14px;line-height:1.7;margin:8px 0;">${paraText}</p>`;
    }
  }

  if (inList) html += '</ul>';
  return html;
}

const bodyHtml = parseMarkdown(content);

const formattedDate = new Date(data.generated_at).toLocaleDateString('en-US', {
  weekday: 'long', year: 'numeric', month: 'long', day: 'numeric'
});

const newsletter_html = `<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width,initial-scale=1.0">
</head>
<body style="margin:0;padding:0;background-color:#f0f2f5;font-family:Arial,Helvetica,sans-serif;">
  <div style="max-width:600px;margin:32px auto;background:#ffffff;border-radius:8px;overflow:hidden;box-shadow:0 2px 12px rgba(0,0,0,0.10);">

    <div style="background:#1a2744;padding:28px 32px;">
      <div style="color:#e85d04;font-size:10px;font-weight:700;letter-spacing:0.12em;text-transform:uppercase;margin-bottom:6px;">PING IDENTITY</div>
      <div style="color:#ffffff;font-size:20px;font-weight:700;margin:0;">Product Intelligence</div>
      <div style="color:#94a3b8;font-size:13px;margin-top:4px;">Weekly Intel &mdash; ${data.week}</div>
    </div>

    <div style="padding:28px 32px 20px 32px;">
      ${bodyHtml}
    </div>

    <div style="background:#f8fafc;padding:16px 32px;border-top:1px solid #e5e7eb;">
      <p style="color:#9ca3af;font-size:11px;margin:0;text-align:center;">
        Generated by Product Intelligence OS &middot; ${formattedDate}
      </p>
    </div>

  </div>
</body>
</html>`;

return [{ json: { ...data, newsletter_html } }];
```

- [ ] **Step 3: Verify the code handles edge cases**

Walk through these cases mentally before applying:
- `**text**` at start of a bullet: regex `\*\*(.*?)\*\*` → `<strong>$1</strong>` ✓
- Multiple `**` pairs on one line: non-greedy `.*?` handles each pair ✓
- Empty `newsletter_content`: defaults to `''`, produces empty body ✓
- Content shorter than 2000 chars (no second chunk needed): no issue, single pass ✓
- `inList` left open at end of content: closed after loop ✓
