Notion Databases

Notion is the human-readable output and review layer. Structured findings land here as Competitor Cards; newsletters are archived here each Friday.

warning_amber
Notion Node v2.2 Bug
The n8n Notion node v2.2 has a rich_text bug: property values are silently sent as blank. All workflow writes to Notion use HTTP Request to https://api.notion.com/v1/pages directly with predefinedCredentialType: notionApi. Never use the n8n Notion node for writing rich text properties.

Competitor Cards
One page per competitor per week, updated by Competitor Intelligence on Tuesdays and Thursdays. Contains the week's gap analysis, parity claims, recommended actions, and confidence scores.
Written by: Competitor Intelligence · Credential: YOUR_NOTION_CREDENTIAL_ID
Weekly Newsletters DB
Weekly Newsletters
Archive of every Friday newsletter. Each page: title format Weekly Intel: March 2026. Properties: week, findings_count, generated_at. The full newsletter text is stored as page body content.
Written by: Newsletter · Every Friday morning

code Write Pattern

All Notion writes use this HTTP Request pattern:

POST https://api.notion.com/v1/pages Headers: Content-Type: application/json Notion-Version: 2022-06-28 Credential: predefinedCredentialType: notionApi credentialId: YOUR_NOTION_CREDENTIAL_ID Body (raw JSON): { "parent": { "database_id": "YOUR_NOTION_COMPETITOR_DB_ID" }, "properties": { "Name": { "title": [{ "text": { "content": "..." } }] }, "Week": { "rich_text": [{ "text": { "content": "..." } }] } } }
