Google Sheets Schema

The raw data layer. One workbook, 7 tabs. Every workflow reads from or writes to at least one of these tabs.

info
Workbook ID
Workbook ID: YOUR_GOOGLE_SHEETS_ID · Google Sheets OAuth credential: YOUR_GSHEETS_CREDENTIAL_ID

config: Competitor URL registry

One row per competitor URL. Add rows here to add new sources. Only rows with active = TRUE are processed by Market Watch.

FieldTypeDescription
competitor_idstringShort identifier: okta, auth0
namestringDisplay name: Okta, Auth0
tierstringbroad (Phase 1: all sources are broad tier)
source_typestringdocs, changelog, blog, github, release-notes, website
urlstringFull URL to monitor
activebooleanTRUE to include in daily Market Watch runs

change_snapshots: MD5 hash per URL

Stores the last-known content fingerprint for each URL. Market Watch compares against this to detect changes.

FieldTypeDescription
competitor_idstringReferences config.competitor_id
source_typestringReferences config.source_type
source_urlstringThe URL being tracked
last_hashstringMD5 hash of last-seen page content
last_checkedtimestampWhen Market Watch last visited this URL
last_changedtimestampWhen the hash last differed from the previous hash

evidence_log: Raw Market Watch findings

Every finding from Market Watch. Status new → picked up by CI. Status processed → already analyzed. Status archived → excluded from newsletters.

FieldTypeDescription
ev_idstringUnique ID: EV-{competitor}-{timestamp}
date_founddateDate this evidence was detected
weekstringWeek label, e.g. 2026-W13
competitor_idstringokta or auth0
source_typestringType of source that changed
source_urlstringURL where the change was detected
observed_factstringWhat is explicitly stated in the source: no inference
analyst_interpretationstringWhat this might mean strategically: labeled as interpretation
lanestringOne of the 6 strategic lanes
importance_scoreinteger1–5: How meaningful for Ping's product scope
confidence_scoreinteger1–5: How certain the claim is real
evidence_strengthstringdirect | inferred | weak | speculative
statusstringnew | processed | archived

internal_capability_map: Ping's own capabilities

Rebuilt every Monday by the Internal Product Specialist. The source of truth for gap analysis in CI. Support maturity vocabulary is controlled: only 5 values allowed.

FieldTypeDescription
feature_idstringUnique capability identifier
lanestringOne of the 6 strategic lanes
feature_namestringName of the capability or feature
support_maturitystringproduction_mature | documented | partial | unclear | sample_only
source_typestringType of source this was extracted from
source_urlstringURL of the source document
evidence_summarystringWhat the source says about this capability
confidence_scoreinteger1–5: How certain this capability assessment is
maturity_reasonstringWhy this maturity level was assigned. Prefixed with [parser-cap] if a parser safety cap overrode Claude's output.
weekstringWeek this was extracted

structured_findings: Processed CI output

Written by Competitor Intelligence. Cleaner and more actionable than raw evidence_log. Read by the Newsletter every Friday.

FieldTypeDescription
finding_idstringUnique ID: SF-{competitor}-{timestamp}
weekstringWeek label
competitor_idstringokta or auth0
gap_vs_pingstringWhat competitors have that Ping may not (anchored vocabulary)
parity_vs_pingstringWhere competitors and Ping appear to match (with calibration)
ping_advantagestringWhere Ping appears stronger
recommended_actionstringWatch | Validate | Draft Brief: no other values
confidence_scoreinteger1–5: Overall confidence in this finding
review_flagbooleanTRUE if Claude flagged this finding for human review
statusstringnew | reviewed | archived

execution_log: Orchestrator run history

Every Orchestrator run is bookended here: one row opened at start, updated at completion. Also receives weekly audit summaries from Memory & Audit.

FieldTypeDescription
run_idstringUnique run identifier, e.g. RUN-2026-03-31T06-30-00
datedateDate of this run
workflow_namestringName of the workflow (or audit_summary for weekly audit)
statusstringrunning | success | failed
started_attimestampWhen this run began
ended_attimestampWhen this run completed (null if still running)
notesstringAudit summary or run notes

error_log: All workflow errors

Permanent audit trail of every failure across all workflows. Written by Error Handler.

FieldTypeDescription
idstringUnique error identifier
timestamptimestampWhen the error occurred
run_idstringOrchestrator run ID when this error occurred
workflow_namestringWhich workflow crashed
node_namestringWhich node inside that workflow crashed
error_messagestringThe raw error message from n8n
severitystringcritical | non-critical
resolvedbooleanManually set to TRUE once investigated
