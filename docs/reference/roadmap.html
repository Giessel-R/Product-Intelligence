build Future Stages
6
Stage 6: Run Telemetry
Add structured telemetry to each production run. Track: total URLs fetched, pages changed (MD5 mismatch), items dropped by relevance gate (FALSE branch), Claude (Haiku) calls made, CI evidence items processed. Write a run_summary row to execution_log at the end of each Orchestrator run. This makes cost trends and gate effectiveness measurable over time.
7
Stage 7: External Webhook Trigger
Add a Webhook Trigger node to the Master Orchestrator and register it on an external cron service (e.g. cron-job.org) to fire at 7:00 AM PT Mon–Fri. Eliminates the missed-fire-on-restart risk: if Docker restarts after 7 AM on a weekday, the external cron will still call the webhook and trigger the run. Currently the internal n8n scheduler can miss a run if the container restarts after the scheduled time.
expand_more Phase 2: Expansion
group_add
Expand to 10 Competitors
Add rows to the config tab in Google Sheets: no code changes required. The system is designed to scale horizontally. Each new competitor gets its own URL rows; Market Watch picks them up automatically on the next run. Phase 1 is Okta and Auth0. Phase 2 targets expanding to Microsoft Entra, ForgeRock, Sailpoint, and others as prioritized by the team.
view_kanban
Gap Board (Notion Kanban)
Build a Notion Kanban board that surfaces structured_findings items with recommended_action: Draft Brief or review_flag: TRUE as actionable cards. CI would write cards directly to the board. Product managers could triage, assign, and track competitive gaps through the same Notion workspace already used for the newsletter.
pattern
Pattern Detection Workflow
Add a weekly pattern detection pass that looks across 4+ weeks of structured_findings to identify sustained competitor momentum in a lane (e.g., "Okta has shipped 4 AI_AGENT_IDENTITY items in 3 weeks"). Triggers a separate alert rather than folding into the newsletter.
auto_awesome Phase 3: Executive Layer
summarize
Monthly Strategy Memo (Claude Opus)
Once per month (1st Friday), run Opus against the full month of structured_findings to produce an executive-level competitive briefing. Focus: cross-competitor patterns, strategic themes emerging over 4 weeks, recommended priorities for the quarter. Delivered as a Notion page and email. This is the only use case for Opus: cost justified by monthly frequency and strategic value.
edit_note
Requirement Draft Generator
On-demand webhook trigger. Takes a competitive finding (by ID or lane) and generates a draft product requirement in structured format: problem statement, user stories, acceptance criteria, and Ping parity gap context. Reduces time from "we see a gap" to "here's a draft spec." Phase 3 feature, design TBD.
