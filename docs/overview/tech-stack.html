Tech Stack

The full system runs on ~$15/month. Every tool was chosen for zero marginal cost, except Claude: which is the only component that actually requires spending money.

layers Stack Overview
ToolWhat It IsWhy It's HereCost
n8n Self-hosted workflow automation Orchestration, scheduling, node chaining. Already running: no new infrastructure. $0
Claude API Anthropic LLM API (Haiku + Sonnet) All AI work: classification, extraction, gap analysis, newsletter writing. Haiku for speed; Sonnet for depth. ~$15–30/mo
Google Sheets Cloud spreadsheet Raw data layer. 7 tabs. Config, evidence, findings, capability map, run logs, error log. Easy to inspect and edit by hand. $0
Notion Wiki / database workspace Output layer. Competitor Cards updated weekly by CI. Weekly Newsletters archived here. Human-readable review surface. $0 (free tier)
Jina AI Reader Web-to-text API Used by IPS to fetch my company documentation pages as clean Markdown. Endpoint: r.jina.ai/{url} $0 (free tier)
Gmail (n8n node) Email via Google OAuth Delivers the weekly newsletter and critical error alerts. No SMTP setup required: uses n8n's Gmail credential. $0
Total ~$15–30/mo
psychology AI Model Tiers

Two Claude models are used, matched to task complexity. The right model for the right job keeps costs low without compromising quality.

TierModelUsed ForApprox Cost
Background Haiku Market Watch: change classification, lane tagging, importance/confidence scoring. High volume, low depth. ~3,000 chars input per call. ~$0.001/call
Main Brain Sonnet Internal Product Specialist (capability extraction), Competitor Intelligence (gap analysis), Newsletter (writing). Low volume, high depth. Handles nuance, maturity-aware reasoning, structured JSON output. ~$0.01–0.05/call
Executive Opus Monthly Strategy Memo: Phase 3, not yet built. Once-per-month executive synthesis. Highest reasoning quality. Phase 3
info
Credential Pattern
All Anthropic calls use predefinedCredentialType: httpHeaderAuth with credential ID YOUR_ANTHROPIC_CREDENTIAL_ID. The $env.ANTHROPIC_API_KEY pattern is blocked in HTTP Request node headers: use the n8n credential system instead.
